# Decisions Index

One note per durable choice: the decision, the rejected alternative, and the reason.
Decisions are the memory code and git history cannot record. Each lives in
`Decisions/` with `type: decision`, `date`, `project` (the project note's name), and
`reviewed` frontmatter; the table below renders from it, newest first. Sessions
capture decisions into `Auto Memory/` via the decision-capture skill; the groom run
promotes each capture into its own note.
