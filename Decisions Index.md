# Decisions Index

One note per durable choice: the decision, the rejected alternative, and the reason.
Decisions are the memory code and git history cannot record. A decision note carries
`type: decision` and `date` frontmatter; the table below renders from it. Small
decisions live as dated bullets here instead. Sessions capture decisions into
`Auto Memory/` via the decision-capture skill; the groom run promotes them here.
